# Synthetic format example

`synthetic.csv` is an artificial three-sample illustration using the exact v1.5 recorder columns. It includes START, one battery row and a laptop completion event. It deliberately omits the full LED sequence and is not a complete protocol trace, sensor recording, calibration reference or evidence of physical performance.

Expected inspection: 3 samples, 0.02 seconds between first and last sample, 100 Hz, zero sequence gaps. Empty board time on COMPLETED is intentional. No real ride data was supplied.
